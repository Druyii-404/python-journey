# Python Learning Journey

> A public, living repository documenting one person's path from zero to confident Python developer — covering creative coding, simulation, visualisation, and eventually physical computing.

---

## About This Project

This repository is both a **learning log** and a **resource for others** who might want to follow a similar path. Everything here is built in real sessions, including the wrong turns, the restarts, and the moments where something finally clicks.

The projects built along the way are tracked here from first line to completion, with the reasoning behind decisions documented alongside the code itself.

---

## A Note on AI Assistance

This project uses **AI as a supporting tool** throughout — not to write code on my behalf, but in the following ways:

- As a **guide and coach**, asking questions, pointing toward resources, and helping diagnose problems without simply solving them
- As a **documentation assistant**, helping maintain and structure the three core documents below
- As a **consistency checker**, keeping the learning path coherent across sessions

The AI model in use is tracked in each document. If the model changes at any point during this project, that transition is noted with a date so the reader understands any shift in approach, capability, or style.

**Current model:** Claude Sonnet 4.6  
**Project started:** June 1, 2026

## The Three Core Documents

This repository maintains three documents that serve different purposes and audiences. They cross-reference each other where useful.

| Document | Style | Purpose |
|----------|-------|---------|
| [Encyclopedia](docs/encyclopedia.md) | Reference / lookup | Every syntax element, function, and keyword encountered — with definitions and examples |
| [Guidebook](docs/guidebook.md) | O'Reilly-style narrative | Concepts explained in a structured, teachable order — independent of the order they were actually learned |
| [Journal](docs/journal.md) | Session log | Date-stamped record of each session — what was covered, what went wrong, what landed |

## Influences & Direction

The creative direction for this project draws from:

- **Sebastian Lague** — for the idea that code can produce genuinely beautiful and surprising things; simulations, visualisations, and emergent systems
- **Azeron / atarabyte** — for the longer-term interest in physical computing and custom input devices

The learning path runs roughly: Python fundamentals → creative/visual coding → physical computing (MicroPython, microcontrollers). Hardware design (PCBs etc.) is acknowledged as a future interest but is out of scope for now.
